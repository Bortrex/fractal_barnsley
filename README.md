# Barnsley fern

The Barnsley fern is a fractal named after mathematician Michael Barnsley. This small Python project is from my early days learning to program, and I keep it as part of that history.

The script repeatedly applies one of four affine transformations to a point, choosing each transformation with a fixed probability.

![Example Barnsley fern generated by the script](barnsley.png)

The `barnsley.png` is an example .

## Running it

Use Python 3.X The only dependency is Pillow.

From the repository directory:

```sh
python -m pip install -r requirements.txt
python barnsley.py
```

By default, the script generates a 1,000 × 1,000 image using one million iterations, saves it as `barnsley.png` in the current directory, and opens it in an image viewer. Saving overwrites an existing file.

## Command-line options

- `--iterations INTEGER`: number of iterations, zero or greater (default: `1_000_000`).
- `--seed INTEGER`: optional random seed for reproducible output with the same parameters.
- `--color COLOR`: fern color as a Pillow color name (default: `#649600`, RGB 100, 150, 0).
- `--background COLOR`: background color in the same format (default: `black`).
- `--output PATH`: output image filename or path (default: `barnsley.png`).

Use `python barnsley.py --help` for help. For example:

```sh
python barnsley.py --iterations 250000
python barnsley.py --iterations 1000000 --seed 42
python barnsley.py --color darkgreen --background white
python barnsley.py --seed 42 --output fern_seed42.png
```

# Small update
## Gallery mode

```sh
python barnsley.py --gallery
python barnsley.py --gallery --seed 42
```

Gallery mode saves four 1,000 × 1,000 images in the current directory, no opening any viewer:

| File | Fern / background | Iterations |
| --- | --- | --- |
| `barnsley_classic.png` | Default green / black | 1,000,000 |
| `barnsley_autumn.png` | Dark orange / maroon | 1,000,000 |
| `barnsley_blue.png` | Deep sky blue / midnight blue | 1,000,000 |
| `barnsley_high_density.png` | Default green / black | 3,000,000 |
